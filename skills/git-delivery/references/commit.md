# Atomic commits

1. Inspect `git status --short --branch`, the owned diff and the index. Read branch and signing rules before committing. Do not commit on a protected branch or automatically reset, rename or take over an existing branch or worktree. No upstream is needed for local work.
2. Choose the narrow repository checks for changed behavior. If formatting is needed, format only owned files before lint and inspect the formatter's changes. Reuse checks for the same content, commands and environment. After edits repeat affected checks only. Docs alone do not require an application build. Report failures or unavailable runs and their owner; do not treat them as green or skip a required gate.
3. For a substantial diff in indexed code, use the shared `code-navigation` guidance. Run `ripwire <repo> --quality-delta` against the verified baseline for the owned diff, and `--edit-check` for changed symbols when contracts or callers matter. Confirm the comparison includes the actual staged and unstaged changes in scope; an empty comparison is not proof of coverage. State unavailable or partial coverage and verify affected contracts directly; repository checks still apply.
4. One commit is one self-contained change with its regression tests. Separate independent work, not files or layers that cannot pass on their own. Use the repository's exact subject/body convention; absent one, write a short subject describing the outcome.
5. Select only owned paths or hunks and inspect the candidate commit. Prefer the client's selective commit tool when available; never stage everything. Exclude unrelated hunks, credentials, dumps and private notes. Use normal hooks and configured signing. If a hook changes files, inspect its changes and select only the intended edits before retrying; do not amend, bypass hooks, disable signing or overwrite other work to pass a hook. If authorization is blocked, preserve the work and name the exact owner action without exposing secrets.

Return the commit SHA, covered checks and limits. Stop at the local commit unless push or PR/MR work was also assigned.
